# 4neurons MNLP project code - Running instructions

## Structure

Because our code quickly went from a unified codebase to largely diverging branches,
we have decided to not try and merge them artificially, and instead keep them separate.

The code for the different branches is located in the following folders:

- `general_knowledge/`: code for the "general knowledge" task.
- `maths/`: code for the "maths" task.
- `multilinguality/`: code for the "multilinguality" task.
- `safety/`: code for the "safety" task.
- `group/`: code for the "group" model.

In each folder, you will find a `README.md` file with instructions on how to run the code for that branch, leading to the results presented in our report.
